- Fixed browser launcher startup: test port availability by binding, so a
  slow refused connection cannot be mistaken for a conflict. Automatically
  choose and remember another usable port when the preferred one is occupied.
- Keep one visible language picker in the desktop top navigation. Browser
  pages retain their own controls, and all views still share one preference.

  using Elementarium.exe instead of leaving a broken table or atlas shell.
- Refreshed application screenshots and checked real launcher startup,
  automatic port selection, browser rendering and desktop language switching.

# Elementarium 3.3.0

- Corrected both facial VII and accessory XI nerve pairs with a shared
  skeletal registration. Facial VII includes all six corresponding source
  components per side. Individual trunks are not stretched to unrelated extents.
- Added independent list-collapse arrows beside anatomical systems.
- Added named local views: save, load, rename, delete, JSON backup export and
  import. Full visibility/transparency, selection, ghosting, isolation, depth
  and camera state are preserved. Loading keeps the current app language.
- Kept the Windows browser edition at a stable local origin for saved views.
  A compatible running server is recognized by the content fingerprint.
- Preserved the English Windows setup wizard and optional launch checkbox,
  Linux package, offline models and shared SK / EN / IT / LA preference.
- Added updated application screenshots and nerve-alignment evidence.

All 2,827 structures were checked by actual rendering from six directions.
The 2,751 retained structures preserve the reference materials and compressed
world bounds. Source application checks include saving a view with more than
200 hidden parts, exact opacity/camera restoration and real JSON backup transfer.
See the package verification reports for the final native/browser persistence
checks. Linux payload structure is checked on Windows; live Linux is untested.

The independent geometry/license treatment remains unchanged. The accessory
nerve uses the supplied DBCLS trunk; fourteen small authored nerve courses
remain marked as illustrations. See NERVE_ALIGNMENT.md and LICENSE_AUDIT.md.
