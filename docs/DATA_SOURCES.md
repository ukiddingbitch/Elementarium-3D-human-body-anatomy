# Data sources

Element numerical facts: NIH/NLM PubChem periodic-table dataset (2026-11-11).
Element prose: original Elementarium editorial text; Slovak, English, Italian
and Latin. Italian prose is machine-assisted; chemical names are curated.
The wavelength/frequency calculator remains independent of any spectral-line
compilation. NIST SRD 108 line data is not distributed.

The atlas restores all 2,827 original selectable objects from the supplied
Z-Anatomy export. Independent DBCLS 4.3, HRA and OpenEar geometry replaces the
identified legacy cranial-nerve, urinary and ear candidates. Fourteen minor
nerve courses are authored illustrations, identified in their cards and in
geometry-notes.json. Two unidentified legacy source objects remain unidentified.

The source Z-Anatomy TA2.csv supplies Italian and Latin terminology; additional
editorial translations retain the source names and are not certified clinical
terminology. Slovak curation remains separate. Wikipedia excerpts identify
their exact revision, authors, license and shortening. Slovak labels currently
cover 953 of 1,643 base names; remaining specialized names retain the English
source label. Italian and Latin tables cover all base identifiers, including
explicit unidentified-object labels. Other summaries are
original system contexts, not claimed structure-specific medical definitions.

The per-part source register, hashes and model changes are in
anatomy-source/public/models/model-provenance.json. Full attribution, licenses
and primary source links are in LICENSE, NOTICE and docs/LICENSE_AUDIT.md.
Model registration combines edited geometry from different sources; it is
educational and unreviewed, not a model of one measured person. The phase view
is an approximation, not a complete pressure-dependent phase diagram.
