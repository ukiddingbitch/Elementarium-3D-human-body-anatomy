ELEMENTARIUM 3.3.1 - LINUX (64-bit x86-64)

INSTALLATION
This Debian package is intended for Ubuntu 22.04 or newer, Linux Mint 21 or
newer, and Debian 12 or newer with a graphical desktop.

Open elementarium_3.3.1-1_amd64.deb with your distribution's package installer
(Software Install, GDebi or Discover), then choose Install. If it opens as an
archive, use Open With and select the package installer instead.
Installation requires an administrator password.
Launch Elementarium from your applications menu after installation.

OFFLINE USE
The application includes its own runtime, 118 elements, seven anatomy models,
fonts, text and model decoders. No terminal, web server, Python or Node.js
installation is needed to use it. The atlas opens inside the same window.
Standard Linux desktop libraries listed in the package dependencies are
required. If any are missing, your package manager may need a network
connection or a local package source to install those system libraries once.
The application itself does not download content.

CONTROLS
Switch between the periodic table and anatomy atlas using the top navigation.
Your open element, selected language and atlas camera remain in place.
Close an element detail using the cross button or Esc.
One language setting covers the periodic table, navigation and anatomy atlas:
Slovak, English, Italian and Latin. Original source quotations retain their language.
Resize the atlas list by dragging its right edge or using the arrow button.
Remove the application using your distribution's installed-applications manager.

VERIFICATION
The package structure, metadata, executable architecture, Linux permissions,
checksums and bundled application content were checked on Windows.
A live installation and launch on Linux have not been tested on this machine.
