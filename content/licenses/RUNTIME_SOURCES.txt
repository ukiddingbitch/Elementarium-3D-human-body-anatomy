Native runtime source information — Elementarium 3.3.0
======================================================

Electron v45.3.0:
https://github.com/electron/electron/tree/v45.3.0
Chromium 156.0.8078.96 (exact source including local modifications):
https://chromium.googlesource.com/chromium/src/+/156.0.8078.96/
Dependency revisions: the DEPS file at that tag and electron-DEPS/chromium-DEPS
in resources/third-party/ffmpeg. Chromium's license catalog covers multiple
platforms and optional features; an entry alone does not prove it is bundled.

MPL-covered portions (including Rust Symphonia crates and Mozilla-derived
components) retain their Mozilla Public License notices. Their covered source,
including Chromium's modifications, is available from the pinned Chromium
source tree above and its pinned dependencies. Rust crate sources and their
versions are under third_party/rust/chromium_crates_io/vendor at that tag:
https://chromium.googlesource.com/chromium/src/+/156.0.8078.96/third_party/rust/chromium_crates_io/vendor/
Preserve the notices and source access information when redistributing.

The native FFmpeg LGPL shared library has its actual matching source archive,
Electron patches, build arguments, license texts and replacement instructions
bundled offline in resources/third-party/ffmpeg. There is no application EULA
restricting LGPL replacement or debugging modifications. Other system libraries
used by Linux are provided by the distribution, not bundled by Elementarium.

Chromium's liblouis target produces ChromeOS ChromeVox resources; that optional
resource is not in this Windows/Linux payload. Its appearance in the upstream
all-platform license catalog does not mean a Braille WASM binary is distributed.
